# README の書き換え

## 生じている問題

既存の README が整理されておらず、読みにくい状態だった。具体的には:

- ブランチごとの開発ログ（v1〜v4.4）が README に混在しており、プロジェクトの概要がすぐに把握できない
- コミットメッセージの規約、レンダリング問題のデバッグ記録、コードスニペットなど、README に書くべきでない情報が大量に含まれている
- 見出しの階層が不統一（`#` と `##` と `###` が混在）
- 画像パスにダブルスラッシュ（`//`）が含まれている箇所がある
- コメントアウトされた画像リンクが残っている

## 仮説

README が開発ログとして使われてきた結果、プロジェクト紹介という本来の役割から逸脱していた。開発の過程で情報が追記され続けたが、整理されることがなかった。
